# Research Brat — Synthia Research Mesh

Android research bot built from the earlier Pure Synthia automata lineage plus the Klein Tool context mesh and AutoNovel report architecture recovered from the user's Library and Google Drive.

## Implemented
- registered intake for conversations, notes, Drive/Android files, evidence, reports and coder proposals
- local RAG over the registered corpus
- arXiv retrieval
- PubMed retrieval through NCBI E-utilities
- optional Google Programmable Search RAG
- Android Drive/Files picker, including Google Drive through Android's document provider
- context-generated Klein mesh with deterministic context signatures
- concept mining as a first executable DISEMINER/MESSY/AUTOLING layer
- AutoNovel evidence-grounded report assembly
- additive Synthia Coder automaton
- GitHub Actions APK build

## Canon rules
1. Everything entering the system is registered with provenance.
2. Retrieved evidence and generated synthesis remain distinct.
3. Klein relations are never fixed in isolation.
4. The identical resolved context returns the identical Klein relation.
5. Existing Synthia architecture is preserved; coder output is proposal-only until promoted.
6. Research is primary. Coding is a supporting research automaton.

## APK
Open Actions → Build Android APK → Run workflow. The successful run uploads an artifact named synthia-research-mesh-apk containing app-debug.apk.
